# Reading Summaries

## Quintin (2014): 7 Things You Should Know About Tor

**Not Just for Criminals**  
Tor is often associated with illegal activity, but many legitimate users rely on it. Journalists, activists, and ordinary citizens use Tor to bypass censorship and protect their privacy online.

**Volunteer Powered**  
The Tor network runs on thousands of relays that are operated by volunteers around the world. These relays help route internet traffic through the network and keep it decentralized.

**Anonymity vs. Encryption**  
Tor hides the user's location and identity by routing traffic through several nodes. However, Tor does not always encrypt the data between the final relay and the destination website. For full protection, users should still rely on HTTPS connections.

**The Exit Node Risk**  
The exit node is the final relay before traffic reaches the destination website. If the connection is not encrypted, the exit node can see the data being transmitted. However, the operator of the exit node cannot identify the original user.

**US Government Origins**  
Tor was originally developed by the United States Naval Research Laboratory. Its initial purpose was to protect government communications, but it later became open source and available to the public.

## Shavers & Bair (2016): Hiding Behind the Keyboard

**The Onion Concept**  
Tor uses a system known as onion routing. Data is wrapped in several layers of encryption. Each relay removes one layer to reveal the next destination. No single relay knows both the origin and the final destination of the traffic.

**Performance Trade-off**  
Because Tor routes traffic through three relays that may be located in different parts of the world, browsing becomes slower than normal internet use.

**Hidden Services**  
Tor also allows websites to operate using .onion addresses. These are called hidden services. In this case, both the user and the website remain anonymous because the server location is also hidden.

**De-anonymization**  
Law enforcement rarely breaks Tor itself. Instead, they often identify users through operational security mistakes. Examples include revealing personal information online or repeatedly using the same usernames across different platforms.

### The Debian Attempt

**What I Tried**  
I tried installing the Tor Browser Launcher using the command:

sudo apt install torbrowser-launcher

**Why It Failed**  
Debian’s default "Main" repositories only include software that is completely free and open source. The Tor Browser Launcher is located in the **contrib** repository, which was not enabled in my system.

**Missing Dependencies**  
When I attempted a manual download of Tor Browser, another problem appeared. Debian did not have the required library called **libdbus-glib-1-2**, which is needed for the browser to launch its graphical window.

---

### The Ubuntu Attempt

**What I Tried**  
I switched to an Ubuntu virtual machine that was running Ubuntu Server and tried to launch the Tor Browser from the terminal.

**Why It Failed**  
Ubuntu Server does not include a graphical desktop environment. It only provides a text based terminal interface. Because Tor Browser is a graphical application, it cannot display its window in a terminal only environment.

**The Headless Barrier**  
Running the command:

./start-tor-browser.desktop

requires an **X Server**, which is part of a graphical desktop environment. Without a GUI, the browser cannot start.

---

### What Should Have Happened

In a working graphical environment, Tor Browser would open normally and connect to the Tor network. It would establish a Tor circuit by routing the connection through three different relays in different countries. After that, the browser would allow access to .onion websites while keeping the user's identity and location anonymous.
